# 水晶之旅归家事件（格式 27）

## 目标与规则

把已有水晶探索、伙伴同行和返回家园串成一次有来源的关系事件，而不是随机弹窗、刷关系点或重复奖励。新增独立 CompanionMemoryComponent；不重写导航、资源、偏好或任务系统。

只有 ResourceNode 的实际采样事务成功后才记录：来源定义带 CrystalSample 发现标识，主人存活、在采样点 8 米内并有视线；伙伴是自己的存活驯服个体，在采样点 6 米内、有视线，且正在跟随/战斗，或是本次实际工作采集者。休息、远处待命、别人的伙伴、隔墙旁观、失败/满包采集、普通资源均不获得此经历。重复采样不覆盖已经记录或已分享的状态；不按全局“研究已解锁”倒推过去的同行经历。

有待分享经历后，主人回原基地工作区（距 BaseOrigin 3D 8 米内且附近有工作站），安全、无遮挡地靠近伙伴 2.5 米并瞄准按 F7。跟随/休息可参与，不打断自动休息和待恢复工作意图。工作/战斗、倒下、他人、危险或其他面板未关闭时拒绝。窗口暂停世界，1 安静致谢 / 2 一起庆祝，或按钮选择；退出键／稍后保留待分享状态。Tab／回车可操作按钮。

分享只写入一次个体回忆，给出不同程序化动作回应，并在瞄准与队伍显示选择。没有额外物品、亲密度、经验、体力恢复、战斗属性、偏好发现或原照料冷却刷新。保存后不重复触发；载入旧快照仍是回到旧时间线，不保证保留快照之后的选择。

## 生命周期与持久化

格式 27 显式写盘，根默认 21 保持冻结。CrystalJourney 状态为 None / Pending / QuietThanks / Celebration。非空仅允许拥有的驯服个体，且玩家已有实际水晶采样记录；未知值和矛盾数据在世界替换前拒绝。倒下保留经历，存活才能分享。1–26 清空未来字段，不根据旧水晶知识凭空补伙伴回忆；原昵称、偏好、发现状态和其他系统按已有迁移规则保留。

成功读档、主人倒下、对话伙伴销毁/离场时关闭窗口并恢复游戏输入；坏档拒绝不替换旧世界。窗口中不允许手动照料/采集。对话伙伴外部倒下时提交应拒绝，可取消；不宣称完整外部状态变化自动关窗矩阵。

## 验收门槛和风险

需要实际资源事务、成功/失败和参与者条件、返家门槛、真实 F7 注册路由/无重复绑定、原生窗口确认/取消/暂停与恢复、双分支、数值和资源守恒、重复拒绝、倒下保留、坏档不替换世界、26 迁移和跨进程重开。最终 Windows 包需完整本地回归、真实 26 旧档以及 D3D12 窗口和队伍新图检查，无 CI。

以下保留开发记录，最终 Windows 包的门槛尚待，当前未作为新交付。上一可运行包为 Windows-Preferences-Release。单事件不是完整关系剧情、长期记忆、语音/正式动画、任意区域或营地支持；原 HUD 遮挡、输入法/实体设备和正式 UI 品质仍待后续。
