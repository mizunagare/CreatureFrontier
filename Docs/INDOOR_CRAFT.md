# 真实原料用于屋内加工

## 本轮目标与实现范围

将上一轮实际付费建成的屋内设施接回正常资源与配方，而不是另加一套生产规则。沿用同一苔跳兽、烬尾兽、原农圃、七模块房屋和原资源点：

1. 原屋内烬尾兽L单选、F跟随，实际出门到屋外原制作设施，用E派工。
2. 烬尾兽实际补采2材料，原废料堆3→1，经验15→17；F停止后同行。
3. 玩家实际行走到原河岸纤维，用原M连续采2纤维，16→14，不增加伙伴采集经验。
4. 保存实际原料中途档，再带原伙伴返屋，T原新建屋内设施、让出通路，伙伴实际进入后关门。
5. 查询原8米＋视线许可，要求**唯一可用设施就是原屋内制作设施**，其他设施不提供许可；不忽略墙体或家具。
6. 原C背包选择“编织建材”、Enter，支付1材料＋2纤维产4材料，最终材料2→5、纤维2→0。重复制作因缺纤维拒绝且不扣物。
7. 原任务、物资、位置与生命保存读取保持；原农夫继续原空圃Work，经验仍40。

本轮修改只增加显式QA入口、原有输入／运动／守恒检查的整合场景和本地脚本，不改普通经济、AI、配方、存档格式或资产。没有自动制造队列或伙伴室内加工动画；实际事务仍由玩家在设施旁通过原背包完成。
