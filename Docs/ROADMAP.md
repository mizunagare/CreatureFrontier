# 开发路线

## M0 — 环境与工程

- 安装 Epic Games Launcher、Unreal Engine 5.8、VS 2022 C++ 工具链、Windows SDK、Git LFS
- 生成项目文件并通过 Development Editor 编译
- 建立 Git 仓库与大文件规则

## M1 — 两周垂直切片

- 第一人称 Enhanced Input、交互射线和 HUD
- 生物数据资产、AI 状态树、伤害与捕捉反馈
- 跟随伙伴协同攻击
- 一个工作台与离线存档
- 灰盒测试地图和一只原创占位生物

## M2 — 可重复游玩

当前进度：第一人称输入、基础 HUD、捕捉、伙伴协战/工作已实现；
单机地图快照存档、基础堆叠背包/消耗品制作和导航避障已加入。仍需完成装备与数据驱动配方、原创美术、
更多伙伴技能、生态区与 Windows 打包性能验证。伙伴经验等级、体力、基地休息恢复和药物救治已加入基础版本。
三种原创几何生物（Mosskip/Cinderkit/Craglet）、独立数据资产和采集/采矿/制造工作专长已加入，
后续继续增加正式动画、技能与生态区内容。
三种物种主动技能、集火指令、减速/减伤/溅射、受击反击与技能冷却存档已加入，
后续继续完善战斗动画、音效、生态区和可重复遭遇。
已加入两处固定人口栖息地、捕捉/击败后延时补充、近距离安全检查及刷新存档，
其中 Crystal Rise 为 Lv5 岩系首领，已加入晶震预警/范围攻击、掩体与高度躲避、
首领冷却存档，以及地面战利品/容量溢出保留/战利品存档；生态美术与战利品表仍待实现。
基地建造已加入采集/采矿/制造/农圃/食槽/运输站六类设施、网格预览、范围/占用/支撑验证、材料消耗、拆除返还，
以及设施稳定 ID 存档和工作关联恢复；动态导航支持运行时设施变化。
基础农圃已加入工作产食物、Mosskip 耕作专长、口粮制作、伙伴饱食度与手动喂食，以及相关存档迁移。
自动食槽已接入独立库存、玩家补给、伙伴取食与任务恢复、寻路超时和库存存档。
农圃已改为本地库存生产，运输伙伴实际取走并向食槽送货；携带量随快照保存，支持部分卸货、
改派保留、倒地回收和携带食物应急进食。真实寻路生产—运输—进食与守恒/迁移检查已接入回归。
疲劳/饥饿停工已加入自动休息与阈值复工、手动指令覆盖、倒地/拆除取消及待复工状态存档，
支持持续生产—休息—继续生产循环；旧版休息保持原意图，不自动改为工作。
伙伴分工已加入 L 瞄准选择、K 全体切换，F/E/T/Q/G 可只控制一只伙伴，其他伙伴继续原工作。
倒地/失去选择/单只模式读档后安全阻止指令，避免误召回全体；不同设施分配仍随快照保存。
当前提供指令范围 HUD、Tab 队伍名单、键盘循环浏览与确认选择、自动分页和读档后名单重建。
面板显示状态/需求/工作，选择仍受距离/视线/存活限制；已接入自动回归与双页离屏预览。
伙伴图鉴已加入瞄准发现、捕捉资料解锁、物种去重、离队历史保留、键盘浏览、快照存档和旧档迁移。
新手旅程已串联发现、捕捉、伙伴产材料、农圃产食物和精英捕捉/击败，提供常驻提示、
顺序手动领奖、整组容量校验与进度/背包共同快照；旧档不虚构历史生产与击败归属。
当前为固定五步引导，后续仍需数据驱动任务、剧情内容、NPC 交互和完整进度设计。
玩家倒地已接入 R 原基地安全重生：保留世界/物资/伙伴工作，取消追击与未完成战斗，
检查地面/碰撞/敌人距离，并提供攻击会结束的 3 秒临时保护；倒地存档仍可恢复后重生。
当前不含床位检查点、死亡掉包或营救任务，伙伴不会随玩家重生而治疗/传送。
玩家基础装备已加入长矛/护甲制作与穿戴、攻击/减伤、第一人称占位模型及短刺表现、
装备快照/旧档迁移/异常记录拒绝；成本和效果集中在独立组件默认属性。
玩家近战已从远距离射线改为短距离球体扫掠，区分徒手与长矛触及范围/间隔，
长矛起手后按当前视线重判，阻挡物与伙伴可挡住攻击，切武器/建造/倒地/读档取消待结算刺击。
仍需连续武器网格碰撞、手臂/服装美术、动作反馈、装备菜单、数据资产配方、耐久与多样装备，当前不是完整动作/物品化系统。
图鉴按物种数据资产记录，不提前显示未发现物种；已加入距离/视线校验和异常存档拒绝测试。
伙伴命名、完整编队、收纳、图鉴肖像/收集奖励与任务仍待开发。
墙屋、完整种植流程、通用多物品仓储、复杂运输策略与设施升级尚未实现，基地系统仍为基础版本。
Starter Valley 已加入基地棚屋/土路/树丛/晶簇/边缘岩壁的原创几何场景，并保留旧掩体与建造空间。
栖息地居民加入导航闲逛、领地返程重置、返程保护和锚点存档；教学区三只生物仍固定。
已提供离屏渲染三视图检查入口。正式角色/环境美术、扩展地图、资源生态与复杂生活行为仍待开发。

Windows Development 独立程序已生成，捕捉/工作、背包、跨进程存档及导航测试可由
`Scripts/Test-Packaged.ps1` 在安装包中运行。已进行真实显卡窗口检查并修复天空、
曝光、静态光照提示及出生点围攻问题；正式帧率/内存基准测试尚未完成。

- 背包、装备、制作、掉落
- 伙伴技能、成长、队伍管理
- 基地建造和多类工作
- 三个生物族系、一个小型生态区、首领遭遇

当前可玩性增量：Esc 原生键盘暂停菜单（真正暂停模拟），保存、二次确认读档、倒地重生、二次确认退出；F1 按需查看帮助，常驻 HUD 精简为核心状态和当前目标。暂停状态、确认状态与帮助面板不写入存档，格式仍为 15。新增独立存档的菜单回归，检查真实时间下世界计时冻结和恢复。鼠标菜单、中文字体与完整设置界面仍待开发。

背包/制作交互增量：C 实时面板查看四类库存与装备，五配方上下循环/Enter 单次制作，共用原有制作入口与消耗规则，展示缺料、满格、工作台距离和已拥有原因。菜单选择为临时状态，存档仍为 15。增加五配方/拒绝路径/面板互斥/存档自动化测试与离屏预览；鼠标交互、批量制作、数据资产配方和通用物品系统仍待开发。

宠物表现增量：三物种程序化四足步态、呼吸/眨眼、休息蜷伏、工作/蓄力/扑击/受击与倒地姿态；所有变换只作用于可见模型，地面预警圈独立于身体。加入真实 AI 攻击触发、部件漂移/碰撞/导航隔离和读档重建回归。仍需正式骨骼模型、动画资产、转身/脚底贴地、声音和完整动作状态机，当前程序化灰盒不替代这些内容。

族系策略增量：叶/石/焰三角克制（1.5 优势、0.75 受抗、同系 1），统一受伤入口用于生物普攻/技能/溅射/首领范围攻击，护盾随后减伤，玩家/环境保持普通伤害。瞄准提示按 L/K 指令组统计存活伙伴，图鉴提供族系关系，战斗反馈显示实际伤害。存档格式仍为 15，新增九组合及真实多目标技能、首领、存档回归。后续仍需更多族系/技能与实战平衡。
