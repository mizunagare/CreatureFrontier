# 开发路线

## M0 — 环境与工程

- 安装 Epic Games Launcher、Unreal Engine 5.8、VS 2022 C++ 工具链、Windows SDK、Git LFS
- 生成项目文件并通过 Development Editor 编译
- 建立 Git 仓库与大文件规则

## M1 — 两周垂直切片

- 第一人称 Enhanced Input、交互射线和 HUD
- 生物数据资产、AI 状态树、伤害与捕捉反馈
- 跟随伙伴协同攻击
- 一个工作台与离线存档
- 灰盒测试地图和一只原创占位生物

## M2 — 可重复游玩

当前进度：第一人称输入、基础 HUD、捕捉、伙伴协战/工作已实现；
单机地图快照存档、基础堆叠背包/消耗品制作和导航避障已加入。仍需完成装备与数据驱动配方、原创美术、
更多伙伴技能、生态区与 Windows 打包性能验证。伙伴经验等级、体力、基地休息恢复和药物救治已加入基础版本。
三种原创几何生物（Mosskip/Cinderkit/Craglet）、独立数据资产和采集/采矿/制造工作专长已加入，
后续继续增加正式动画、技能与生态区内容。
三种物种主动技能、集火指令、减速/减伤/溅射、受击反击与技能冷却存档已加入，
后续继续完善战斗动画、音效、生态区和可重复遭遇。
已加入两处固定人口栖息地、捕捉/击败后延时补充、近距离安全检查及刷新存档，
其中 Crystal Rise 为 Lv5 岩系首领，已加入晶震预警/范围攻击、掩体与高度躲避、
首领冷却存档，以及地面战利品/容量溢出保留/战利品存档；生态美术与战利品表仍待实现。
基地建造已加入采集/采矿/制造/农圃/食槽五类设施、网格预览、范围/占用/支撑验证、材料消耗、拆除返还，
以及设施稳定 ID 存档和工作关联恢复；动态导航支持运行时设施变化。
基础农圃已加入工作产食物、Mosskip 耕作专长、口粮制作、伙伴饱食度与手动喂食，以及相关存档迁移。
自动食槽已接入独立库存、玩家补给、伙伴取食与任务恢复、寻路超时和库存存档。
疲劳/饥饿停工已加入自动休息与阈值复工、手动指令覆盖、倒地/拆除取消及待复工状态存档，
支持持续生产—休息—继续生产循环；旧版休息保持原意图，不自动改为工作。
伙伴分工已加入 L 瞄准选择、K 全体切换，F/E/T/Q/G 可只控制一只伙伴，其他伙伴继续原工作。
倒地/失去选择/单只模式读档后安全阻止指令，避免误召回全体；不同设施分配仍随快照保存。
当前提供指令范围 HUD、Tab 队伍名单、键盘循环浏览与确认选择、自动分页和读档后名单重建。
面板显示状态/需求/工作，选择仍受距离/视线/存活限制；已接入自动回归与双页离屏预览。
伙伴命名、完整编队、收纳与图鉴仍待开发。
墙屋、完整种植流程、仓储物流与设施升级尚未实现，基地系统仍为基础版本。
Starter Valley 已加入基地棚屋/土路/树丛/晶簇/边缘岩壁的原创几何场景，并保留旧掩体与建造空间。
栖息地居民加入导航闲逛、领地返程重置、返程保护和锚点存档；教学区三只生物仍固定。
已提供离屏渲染三视图检查入口。正式角色/环境美术、扩展地图、资源生态与复杂生活行为仍待开发。

Windows Development 独立程序已生成，捕捉/工作、背包、跨进程存档及导航测试可由
`Scripts/Test-Packaged.ps1` 在安装包中运行。已进行真实显卡窗口检查并修复天空、
曝光、静态光照提示及出生点围攻问题；正式帧率/内存基准测试尚未完成。

- 背包、装备、制作、掉落
- 伙伴技能、成长、队伍管理
- 基地建造和多类工作
- 三个生物族系、一个小型生态区、首领遭遇

## M3 — 联机与内容管线

- 2–4 人合作、服务器权威、断线恢复
- World Partition、数据层、性能预算
- 自动化构建、资产命名检查、存档迁移

## 完成标准

每个里程碑必须有可打包 Windows 构建、冒烟测试清单和帧率/内存记录。
