# 开发路线

## M0 — 环境与工程

- 安装 Epic Games Launcher、Unreal Engine 5.8、VS 2022 C++ 工具链、Windows SDK、Git LFS
- 生成项目文件并通过 Development Editor 编译
- 建立 Git 仓库与大文件规则

## M1 — 两周垂直切片

- 第一人称 Enhanced Input、交互射线和 HUD
- 生物数据资产、AI 状态树、伤害与捕捉反馈
- 跟随伙伴协同攻击
- 一个工作台与离线存档
- 灰盒测试地图和一只原创占位生物

## M2 — 可重复游玩

当前进度：第一人称输入、基础 HUD、捕捉、伙伴协战/工作已实现；
单机地图快照存档、基础堆叠背包/消耗品制作和静态导航避障已加入。仍需完成装备与数据驱动配方、原创美术、
伙伴技能成长、生态区与 Windows 打包性能验证。

- 背包、装备、制作、掉落
- 伙伴技能、成长、队伍管理
- 基地建造和多类工作
- 三个生物族系、一个小型生态区、首领遭遇

## M3 — 联机与内容管线

- 2–4 人合作、服务器权威、断线恢复
- World Partition、数据层、性能预算
- 自动化构建、资产命名检查、存档迁移

## 完成标准

每个里程碑必须有可打包 Windows 构建、冒烟测试清单和帧率/内存记录。
