# 开发路线

## 当前优先级与状态口径（2026-10-28）

主线为 Windows 单机的“探索—资源—伙伴—家园—下一次探索”，不是无限增加孤立功能。
以下状态限定于当前灰盒和已执行的检查，不代表完整游戏或里程碑最终品质已完成。
当前已验收交付存档格式为 20，兼容读取 1–19。新旧构建和存档备份应分别保留，不能将新档交给旧程序读取。

- **已实现且经过验证**：共享有限资源、单层房间与水晶探索首回路已有回归。本轮加入直接野外资源工作令、就地休息/恢复及格式 20，最终 38 类检查、40 个独立进程通过，跟随保持 3 次重复，一张最终图形检查通过。覆盖边界见下文，不代表完整自动矿场、经济/科技树或任意规模稳定。
- **正在开发**：本轮野外工作令的限定首版已验收，未并行展开其他新玩法。下一独立工作优先复现跟随转向停靠偶发失败，再补野外封堵/重试与长时恢复专项；营地扩展仍未实现。
- **已实现但验证不完整**：任意房间/复杂走廊/拥挤队伍与极限模块/灯数量；资源采集多工人拥堵、任意建筑封堵和长时循环；普通窗口文字稳定性；完整帧率和内存基准。角色/资源/房间仍为几何占位，世界标签偏大且会遮 HUD，灯具只是首版实际点光源。
- **新发现的稳定性风险**：首轮回归跟随 phase 1 曾未在原 12 秒内停靠；最终构建三次重复通过，但根因未定位，不算已修复。未修改跟随算法、放宽距离/时限或删除失败日志；负载相关性尚未证明，优先专项复现。
- **已规划、尚未实现**：迁移营地、更多差异材料与仓储、多层与门窗/楼梯/装饰、洞穴/遗迹、更多区域探索解锁、个体命名/收纳/偏好和关系事件。
- **暂缓实施**：多人联机、服务器与在线服务、完整体素地形、繁殖遗传、商业化系统。
- **已知结构性风险**：普通三类资源仍统一产抽象材料并直接入包，水晶有限经济未做完整平衡；农圃仍无种子/生长阶段；设施成本、装备效果、固定任务仍硬编码；个体生物缺少稳定 ID；玩家/生物/游戏模式职责仍偏多，后续扩展应在明确收益下拆分。
