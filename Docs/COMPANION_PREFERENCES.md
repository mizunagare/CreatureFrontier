# 伙伴互动偏好（格式 26）

## 玩法目标

让玩家在共同生活中发现同物种个体的不同喜好，而不是把亲密度变成被动战斗加成。原 Y 安静抚摸保留，F6 活泼互动新增；都需瞄准自己的存活伙伴、2.5 米、无遮挡、附近安全且世界未暂停。安静照料允许跟随/休息；玩耍只允许跟随、没有待恢复工作意图、体力与饱食均至少 20，成功消耗 5 体力，不消耗食物。

两种互动共用原 30 秒个体冷却，均加原 2 点亲密度（封顶 100）。偏好不加亲密度收益、HP、攻击或经验。非偏好互动仍是友好回应，不扣关系、不因饥饿逼迫喂食。遇到匹配偏好才首次发现，反馈提示并在瞄准/队伍显示记住。连续交替按键不能绕过冷却。拒绝时不扣体力、不发现、不增加关系。

安静动作沿用 Affection 状态，调整为点头/轻摇；玩耍有 Playing 状态、可见弹跳/转身，喜欢的互动回应更明显。变化仅在无碰撞的视觉 Pivot，不移动胶囊、不瞬移导航；仍是程序化占位，不是正式动画/声音或复杂情感模拟。没有投掷玩具、追球或完整关系事件系统。

## 身份、组件和持久化

CompanionPersonalityComponent 管理偏好分配、发现状态、玩耍需求与反馈，角色/玩家复用已有照料门槛和呈现。当前两个偏好为 Quiet / Playful；第一次驯服由稳定 GUID 四段异或的最低位分配，不按物种或昵称决定，不随 Actor 名/编队/重启随机重抽。持久化保存明确偏好，不在新格式加载时重新推导，便于以后拓展真实内容驱动的个性。

格式 26 显式写盘，根默认 21 保持冻结。追加 Preference 与 bPreferenceDiscovered；拥有的驯服个体（含倒下）必须是两种合法偏好之一，其他生物必须 None 且未发现。坏数据在替换世界前拒绝。1–25 忽略未来字段，已有 ID 的伙伴按 ID 迁移为未知偏好，不赠送关系/体力或虚构过去的发现；旧于 22 本来没有稳定 ID 的档仍沿用既有 ID 迁移边界。旧快照恢复不保留其保存后发生的发现。
