# 主界面信息分区（格式仍 27）

## 目标与实现范围

修正伙伴状态压在角色上、任务/反馈抢位、队伍面板下仍绘制瞄准文字的问题。不改变玩法门槛、物品、AI 或存档字段。主界面拆成 WorldHUD、字体边界/布局、队伍与原图鉴绘制职责；不是更换 UI 框架或正式美术重做。

常驻状态左上、反馈其下、任务左下，研究/最近区域右上，仅当前瞄准对象的一张卡在右下。建造模式优先显示建造提示；否则按生物、资源、箱子、设施显示对应上下文，沿用原射线/交互距离。伙伴卡保留身份/HP/需求/工作/技能/照料/偏好/回忆与属性信息。长文按实际字体测量换行并在行数限制处省略，不把文字画到其他卡中。普通主界面中心 20% 宽、40% 高的区域不放信息面板，保留准星与伙伴视野。

队伍打开时主界面右侧对象卡/研究/任务暂不重复显示，队伍行按分辨率缩放、超长名称/状态受行宽约束；原浏览、选择与命名规则不变。危险条独立保留：倒下、瞄准的精英蓄力、玩家近战蓄力、复活保护、返回栖息地按优先级呈现；打开非暂停界面时移到左下空位，避免压住右侧菜单。没有新增透墙/全世界敌人预警。原生暂停窗口独占其屏幕。

帮助、背包、仓储和图鉴内部内容/分页仍为旧版；本轮不声称它们在所有分辨率完整重排。世界空间设施/资源 Label 缩为短名称（资源附余量），不再重复多行热键/状态，字号 12、设施/资源裁剪距离分别 9/6 米；完整状态仍在瞄准卡，未全面重做所有生态招牌。长期目标仍需统一 UI、可访问性、本地化和正式视觉。

## 验收门槛

CFHUDLayoutTest 为纯布局模型：7 个尺寸 × 普通/界面两模式，检查屏幕边界、互不重叠与中心预留，并用刻意重叠/越界负对照防止空断言；不能代替实际渲染。

CFHUDPreview 为 D3D12 实际 Canvas 绘制帧：伙伴、长中文名队伍分页、队伍危险条、帮助危险条、资源、农圃、建造、倒下 8 个场景。HUD 记录实际字体测量边界、面板矩形、当前上下文/警报和省略计数；逐帧确认后截图，保留一段时间再切换场景，避免文件名与下一场景错配。夹具显式设置需求、偏好/回忆、工作意图、精英蓄力和倒下状态，不据此宣称这些行为均由真实战斗触发。实际玩法仍需完整本地回归和旧存档验证。

计划实际检查 960×540、1280×720、1920×1080 的新图；更广尺寸仅模型检查不冒充已目视。绘制帧边界审计只覆盖新主界面和队伍行，不涵盖旧菜单内部全部文字、所有世界招牌或任意字素排版。未知 GPU/默认线程渲染性能和实体输入设备仍待。

当前首轮编译遇到 double 几何坐标的 FloorToInt 返回 int64 与 Min3 的 int32 参数冲突，已明确转换，续编译中；尚未发布新包。上一交付仍为 Windows-Memories-Final。禁止 CI，旧构建与用户存档保留。
