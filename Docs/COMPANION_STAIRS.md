# 伙伴搬料施工楼梯

## 规则与操作

复用现有木楼梯、供料施工和伙伴需求系统，不新增库存或寻路系统。木楼梯仍需12份材料、下层地板及上升方向相邻的已完工二层楼板；完工仍为原16级、每级20厘米的实体踏步。待建状态只有低矮边框和料箱，保留碰撞但不提前提供楼梯或上层导航连接；未来完整楼梯空间照旧预约。

玩家操作：B进入建造，8切到房屋模块，V选择木楼梯，9旋转；对准有效安装位，按住右Shift并左键设置待建工地。先瞄准材料箱按V，再瞄准工地按E派当前伙伴。伙伴从箱中分批搬料，在满足完工胶囊净空的实际接近点施工；饥饿、进食、休息与任务恢复沿用原规则。未完工前不能通行，F取消任务保留携物，X取消工地退还已交材料，尚未交出的携物用Z取回。完工楼梯有人时仍拒绝拆除；待建楼梯的地板支撑也不能移除。

存档写盘升级38：正常37及更早受支持的家园档继续按原迁移规则读取，旧37已完工楼梯合法；伪37待建楼梯必须拒绝且保持当前世界。38档不要交回旧程序。使用新包前独立备份存档，不覆盖旧包。
