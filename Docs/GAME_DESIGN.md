# 幻兽边境 — 游戏设计纲要

当前操作增量：已提供左Shift按住慢行/松开恢复，并用实际慢行绑定、完整方向输入验证洞窟同行与返家循环，见 `Docs/PLAYER_PACE.md`。下文模拟慢步为上一阶段记录；系统层持续按键与Alt-Tab仍未完成验收，技能第一人称空间反馈仍是后续重点。

技能空间反馈首版已实现：实际命中后沿施法者—目标位置显示短时三维轨迹，使用物种配色与差异形体，受普通场景深度遮挡，不改变伤害、射程或消耗。三尺寸显示/实体墙对照与洞窟命中图已验证，同一固定包81类/85进程回归和30个真实旧档读取进程通过。伙伴本体在画外、轨迹短促和占位美术仍有品质缺口，不等于完整战斗表现；详见 `Docs/SKILL_SPATIAL_FEEDBACK.md`。

## 核心幻想

恢复流程正在补综合验收：自然战斗倒地后R返回基地，保留残血敌人/伙伴、物品和有限来源，等待负伤伙伴实际导航返家后再共同冒险，不给伙伴瞬移或免费治疗。图形检查发现倒地对象卡仍提示不可用操作，已改为只读信息和复活/读档指引；最新包三尺寸24图与真实旧档已检查，完整回归尚在执行，见 `Docs/HOLLOW_RECOVERY.md`。不将现有隔离复活规则当成新增功能或完整区域恢复品质。

玩家以第一人称探索开放区域，发现并捕捉有生态习性的生物。伙伴不是库存道具：
它们会同行、战斗、休息，并在基地承担采集、耕作、制造和运输工作。

项目目标是使用 Unreal Engine 5 与 C++ 制作原创的第一人称开放世界生物伙伴 RPG。
项目中文展示名暂定“幻兽边境”。面向玩家的文案统一使用简体中文，后续文档、开发沟通与新增注释使用中文；技术标识、资源路径和存档协议保留，具体见 `Docs/CHINESE.md`。
当前交付平台为 Windows 单机，优先持续可玩、本地打包与存档可靠性；不为尚未确定的联机需求扩展复杂架构。
《我的世界》提供探索、采集和自由建设的方向参考，宝可梦类游戏提供发现、结交、捕捉与培养方向，
《幻兽帕鲁》提供基地协作方向；这些参考不构成复制具体角色、造型、名称、地图、音效或其他专有表达的许可。

## 核心循环

探索世界 → 发现生物与资源 → 结交或捕捉伙伴 → 培养与协作 → 建设家园
→ 获得新的能力与资源 → 探索更广阔的世界。

战斗削弱是捕捉路径之一，不应成为结交所有生物的唯一方式。
已有物种数据驱动的和平结交首版：J向2.5米内健康、平静且周围安全的苔跳兽分享3食物，无需伤害或捕捉器。温顺不等于无条件驯服，食物成本、视线/敌意门槛、受击反击与已有驯服持久化按固定构建验收，详见 `Docs/PEACEFUL_BEFRIENDING.md`；其他物种首领及多阶段信任尚不支持，不等于完整非战斗关系系统。
区域差异应通过资源、生物、危险和奖励体现，而不是仅扩大地图面积。

南侧“余烬洞窟”首版连接初始山谷：有实际碰撞、折返洞道、顶盖和三级烬尾兽栖息地；洞内6份有限机械废件可带回基地用于现有配方，不另赠研究资格或水晶。格式28只对旧版本补新增稳定来源，不补满旧库存，也不复活28中耗尽/缺失来源。几何灰盒及隔离检查见 `Docs/EMBER_HOLLOW.md`；后续一级岩角兽在模拟慢步输入下实际同行、自然三级住民战斗、技能/承伤、拾取战利品、有限采集、返家加工与存读的存活路线已有Windows及D3D12独立证据，见 `Docs/HOLLOW_ADVENTURE.md`。这不覆盖从全新角色自然解锁、完整键盘同行、倒地后区域完整恢复、多伙伴拥堵、长期循环或最终环境品质；键盘慢行操作与技能的第一人称空间反馈仍需改善。

野生生物允许短距离探索、折返和停留，不要求每个固定时间窗口都远离出生点。验证应区分合法巡游与真实卡死，不能为了测试结果强制扩大巡游距离或提高速度。当前栖息地巡游、回巢保护和诊断边界见 `Docs/WILD_ECOLOGY.md`；动态封路恢复、群体行为与生活需求驱动仍未完成。

岩壁应影响发现和战斗节奏。遮挡警戒首版要求野生首次发现、伙伴自动选敌具备视线；野生丢失视线后只追最后看见的位置3秒，再放弃警戒。玩家主动集火与实际受伤反击是独立规则，不等于完整隐身、听觉或追踪系统；验收范围见 `Docs/WILD_AWARENESS.md`，综合区域战斗往返仍需后续验证。同行默认只自动响应敌意目标，不擅自攻击中性/温顺生物，以保留带伙伴和平结交的选择；显式集火仍可进攻中性目标，工作/休息边界不改，具体证据见 `Docs/COMPANION_DEFENSE.md`。可切换的战术姿态和多伙伴策略尚未实现。

## 伙伴关系与生活

伙伴的差异应同时体现在外形、生态、能力、用途、需求、偏好和互动反馈上，不只体现为攻击数值。
现有三物种、工作专长、技能、族系、饱食度、体力、休息、喂食和亲密度是基础，不是完整生态或关系系统。
亲密度阶段目前只记录相处进度；格式 26 已有两种个体互动偏好、发现记忆和不同动作回应，27 加入首次实际共同采样后的归家事件。后续继续丰富共同经历和关系事件，避免只追加被动数值加成。
玩家手动喂食和抚摸在任何世界暂停期间均拒绝，不靠 UI-only 模式替代玩法校验；命名和归家事件窗口确认是明确允许的暂停内操作。边界修复与验证见 `Docs/CARE_PAUSE.md`、`Docs/COMPANION_MEMORIES.md`；其他系统的直接调用暂停边界不据此视为已全部审计。
生物稳定 GUID 已用于跨读档身份和重复记录校验，驯服/倒下不换身份。格式 25 已有个体昵称、原生改名窗口、物种信息并存与短暂动作回应，见 `Docs/COMPANION_NAMES.md`；同名不合并身份，也不改变 Actor/编队排序或授予数值。26 的 Y 安静照料 / F6 活泼互动共用冷却与原关系收益，玩耍需要跟随且体力/饱食充足、消耗体力；匹配偏好才发现并记住，见 `Docs/COMPANION_PREFERENCES.md`。27 的“水晶之旅归家”只在实际成功采样、主人和合格伙伴在场/有视线后记录，回原基地安全靠近按 F7 选择致谢/庆祝，保存一次个体回忆、不发资源/数值奖励，见 `Docs/COMPANION_MEMORIES.md`。收纳、饮食/作息等更广泛偏好、更多关系事件与生活行为尚未实现，不得将单事件等同完整个体养成。

## 伙伴同行与移动

伙伴同行使用真实碰撞与导航，不通过瞬移、关闭碰撞或临时加速掩盖路径问题。
可局部让行、短绕行与重新规划；临时路径应经过可达性与角色通道检查，无安全路线时等待/重试，不穿越障碍。
当前三列灰盒编队的站位是运行时安排，不等于稳定个体身份；大队伍、多层与狭窄通道仍需验证，具体规则和验收边界见 `Docs/FOLLOWING.md`。

## 自由家园与地形边界

真正的建造目标包括地板、墙、屋顶、门窗、楼梯、栅栏、工作设施和装饰。
模块需要明确吸附、旋转、碰撞、结构支撑、拆除/替换、导航更新和快照恢复规则。
当前已加入单层地板、墙、门洞与屋顶，支持地板/墙支撑、拒绝悬空拆除、室内设施和玩家/伙伴真实进出，详见 `Docs/HOME_BUILDING.md`。
六种工作设施与单层房间仍不是完整自由建造；多层、窗、楼梯、可开关门、家具、装饰和正式材质尚未实现。
水晶研究可解锁依附地板、实际发光的常亮灯；这不是完整供电、开关或正式室内照明系统。
玩家可建造依附地板的储物箱，存取现有六类物品，非空拒绝拆除；伙伴可从指定资源真实携带材料/水晶交付，尚不是箱间/农场/制造的通用物流网络。复用房屋支撑、碰撞、GUID 和恢复事务，规则见 `Docs/STORAGE.md` 与 `Docs/CARGO_DELIVERY.md`。
格式 23 扩为九类物品，加入纤维/矿料/机械废件来源与三条原基地加工配方，新增原料复用仓储和携带交付；不改变已经取得的建筑材料或补满旧来源，当前验收边界见 `Docs/MATERIALS.md`。
地形改造与建筑分别设计：先完成模块建筑、资源点、矿点和洞穴探索；完整体素引擎与任意地形挖掘暂缓，须先评估收益与代价。

## 资源、生产与任务一致性

资源必须有明确来源、容量、消耗、产出与补充规则。每种工作应定义开始、执行、完成、中断、失败、重试和恢复语义。
失败不能吞掉资源，重复请求/读档不能重复结算，中断后不能永久卡死。
采集/采矿/制造设施已改接共享有限资源点：玩家和伙伴消耗同一份库存；制造站此阶段回收有限废料，不凭空生成材料。
草丛耗尽后按未暂停的游戏时间恢复，矿石/废料不刷新；资源、冷却和恢复时间从格式 17 起进入快照，详见 `Docs/RESOURCES.md`。
农圃本地库存—搬运—食槽已有基础物流。格式 24 加入种子投入、共享照料生长与成熟收获：玩家近距离 G 交互，伙伴用本地备用种子工作；满仓保留作物，换工人不清零，保存/迁移规则见 `Docs/CROPS.md`。这是单作物、工作量驱动的首版，不是完整自然/离线生长，水肥/季节/枯萎仍未实现。玩家仓储已有多物品守恒存取与伙伴资源交付，食物运输仍独立，通用箱间物流未接入。
草丛/普通矿点/废料仍产抽象材料；精英区域新增独立有限水晶，通过真实采样、返家研究、混合配方和灯具把探索与家园串联，详见 `Docs/CRYSTAL_EXPEDITION.md`。
未选择交付箱时产物仍直接进入玩家背包；玩家可自行带回储物箱。先 V 选择箱子再 E 派伙伴到资源，可将产物装入伙伴最多 3 份的携带库存，实际走到箱子才转移；满箱/受阻等待，取消/倒下/目标丢失保留货物，详情见 `Docs/CARGO_DELIVERY.md`。野外任务仍支持原疲劳/饥饿恢复，详见 `Docs/FIELD_WORK.md`。没有野外治疗或自动战斗护卫；营地扩展、更多差异材料和通用物流网络尚未实现，不将首条回路等同于完整经济或科技树。
受阻任务应保留目标但不提前结算，路线恢复后真实到达才继续；目标丢失时停止旧导航并退出任务，读档不重复发放产出或种出缺失资源。当前仅按固定单只围栏场景及跨进程复验，不代表任意堵路/拥堵/长时工作已稳定。

## 数据与职责边界

逐步将物种、物品、配方、建筑、技能、任务条件与工作类型迁移到数据定义；避免新增多份重复硬编码。
物种使用 Data Asset；六类物品显示/捕捉倍率与七种配方已集中目录，背包显示、旧快捷键与新研究共用配方事务。设施成本、装备效果与固定新手任务仍含硬编码，不能因此宣称全系统数据驱动。
格式 23 将同一目录扩为九类物品/十条配方，原数值 0–5 不重排。新增加工仍是返原基地的一次库存事务，不等于已有自动制造队列或加工设施动画。旧 1–22 快照只补入未记录的新来源，格式 23 的缺失来源不重新种出；测试数量假设随内容更新，但原资源余量与守恒门槛不放宽。
格式 24 在同一目录追加第十类种子和第十一条种子配方，农业组件管理共享生长、输入与收获，生物保留导航/休息/进食优先级。旧农业库存保留但不赠送种子；原工人需要补种子才继续产出。单作物工作量/产量仍是组件代码参数，多作物应再引入定义资产，不宣称全农业数据驱动完成。
玩家、生物、游戏模式、存档和任务系统应有清晰职责。仅拆分源文件不等于完成组件化，不做没有收益的大规模重写。
持久化数据需要稳定标识、迁移、异常拒绝和恢复一致性。设施、资源节点、房屋模块与生物均有稳定 GUID；格式 22 追加生物身份、携带物与订单，24 加农业状态，25 加个体昵称，26 加互动偏好/发现，27 加原始字节编码的归家回忆状态。复用分阶段恢复，旧版本不虚构过去的发现或共同经历；未知回忆字节与归属/水晶研究矛盾数据拒绝。旧生物加载迁移生成身份，写入新档后跨读档稳定，不声称旧文件原本已有身份；昵称不取代 GUID，更多事件仍需继续建设。

## 首个可玩垂直切片

1. 第一人称移动、交互、基础攻击和受伤。
2. 一种野生生物：闲逛、警戒、追击、攻击、倒地。
3. 使用捕捉装置；血量越低，成功率越高。
4. 已驯服生物可切换跟随、战斗和工作状态。
5. 一个基地工作点：伙伴持续产出一种资源。
6. 存档：玩家位置、背包、伙伴列表及伙伴状态。
7. 单机优先，但核心角色和捕捉状态按服务端权威方式编写，为联机留接口。

## 原创性边界

项目借鉴“探索建设 + 生物伙伴”的类型机制，但不复制《我的世界》、宝可梦或幻兽帕鲁的名称、
角色造型、世界观、音效、UI、地图或专有数值。所有生物、技能和视觉语言必须原创。

## 暂缓项

大型无缝开放世界、繁殖遗传、复杂科技树、坐骑、多人服务器和商业化系统，
都放在垂直切片验证好玩之后。

## 开发与验收约束

以当前分支、代码、本文和路线图共同确定目标。每轮只收敛一项可独立验收的工作，写明缺口、方案、影响、风险与验收证据。
编译、进程退出和代码存在不等于交付；必须检查实际行为、资源守恒、异常恢复、存档迁移与现有功能回归。
程序化模型和文字 HUD 均为占位，正式模型、动画、音效、环境、UI 和性能需要单独验收。
所有验证通过明确调用的本地构建、脚本与打包程序执行。禁止新增或启用自动触发 CI；仓库不配置自动 CI 工作流。
保留用户已有修改，不执行破坏性 Git 操作；独立工作验收后及时提交并按约定推送。
