# Creature Frontier — 游戏设计纲要

## 核心幻想

玩家以第一人称探索开放区域，发现并捕捉有生态习性的生物。伙伴不是库存道具：
它们会同行、战斗、休息，并在基地承担采集、耕作、制造和运输工作。

## 核心循环

探索 → 发现生物/资源 → 战斗削弱 → 捕捉 → 培养与配队 → 建设基地并分配工作
→ 制作更好的装备与捕捉工具 → 前往更危险的生态区。

## 首个可玩垂直切片

1. 第一人称移动、交互、基础攻击和受伤。
2. 一种野生生物：闲逛、警戒、追击、攻击、倒地。
3. 使用捕捉装置；血量越低，成功率越高。
4. 已驯服生物可切换跟随、战斗和工作状态。
5. 一个基地工作点：伙伴持续产出一种资源。
6. 存档：玩家位置、背包、伙伴列表及伙伴状态。
7. 单机优先，但核心角色和捕捉状态按服务端权威方式编写，为联机留接口。

## 原创性边界

项目借鉴“生物捕捉 + 生存建造”的类型机制，但不复制宝可梦或幻兽帕鲁的名称、
角色造型、世界观、音效、UI、地图或专有数值。所有生物、技能和视觉语言必须原创。

## 暂缓项

大型无缝开放世界、繁殖遗传、复杂科技树、坐骑、多人服务器和商业化系统，
都放在垂直切片验证好玩之后。
