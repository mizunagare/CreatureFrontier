# 旧地图放置生物的归巢锚点

## 缺口与实现

真实倒地救援曾因旧地图烬尾兽持续追到基地而失败，详见 `Docs/STARTER_RESCUE.md`。该个体没有遭遇ID，`bHasHabitat=false`，原归巢分支因此完全跳过；余烬洞窟个体并非这次追击者。

本次在游戏模式开始、第一帧AI移动和读档前，从关卡实际加载的放置生物记录原地图位置，按生物定义建立本世界锚点目录。仅处理未结交且无遭遇ID的放置对象；它们缺少栖息地时启用原栖息地规则。运行时生成的测试／遭遇对象不会被当作地图放置对象收录，重复读档也不会将已经移动的对象重新登记为出生点。

旧档恢复时，仅对未拥有、无遭遇ID、无栖息地的记录，查询本关卡唯一同定义地图锚点。查不到或地图同定义存在多个锚点时不猜测；有明确栖息地的记录、已拥有伙伴及遭遇生物不覆盖。沿用既有38格式和字段，不重建地图，不改原生物身份、读档位置、生命、等级、经验、漫游半径或1000厘米原追击范围。

当前地图的旧烬尾兽锚点为(1250,450,90)，旧岩角兽为(1500,-550,90)。90为地图原放置高度，实际地面胶囊中心约40；归巢仍复用原水平距离和导航投影，不直接移动角色。不会把烬尾兽已追到基地的存档位置当成出生点。回到原栖息地后的回血沿用原归巢规则，不额外治疗、缩短追击距离或关闭攻击／碰撞。
