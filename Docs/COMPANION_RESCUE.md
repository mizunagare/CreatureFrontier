# 倒地伙伴救助（开发中）

## 本轮目标

让玩家看懂如何帮助倒地伙伴，随后验证“自然战斗倒下—保存退出—回到现场—花费药品救助—共同返家”的真实恢复流程。不是新增免费复活、远程召回或传送功能，不修改存档格式28。

## 既有规则与修改范围

`HealCompanion` 使用可见性射线选择自有伙伴；玩家必须存活，伙伴未满生命，消耗一份药品恢复至多40生命。零生命伙伴也适用。R仅复活玩家，不治疗伙伴。倒地伙伴保留世界位置与携带物，不能自行导航返家。

本轮仅修改WorldHUD对象卡：伙伴零生命时隐藏常规生活/指令提示，展示不能自行返家、P药品救助、有药/缺药指引和Z携带物取回。活伙伴沿用原信息卡。未修改射程、配方、药品消耗、治疗、导航或存档事务。

既有CFCareTest通过直接施加伤害制造伙伴倒地、直接调用HealCompanion检查40生命/一份消耗，并验收存读和基地休息。这不是自然战斗倒地，也不是P输入链、遮挡拒绝或跨进程倒地救助的证明，不应混称覆盖完整救助体验。
