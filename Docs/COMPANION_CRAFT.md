# 伙伴设施加工委托（首版限定验收）

## 玩法与边界

在3米内看向**自建制作设施**，C打开背包选物品配方，Shift＋回车委托一份；再次Shift＋回车取消该设施当前委托。退出背包后，沿用L单选／K全队、E派工。伙伴实际接近设施、视线无遮挡后工作，复用原专长效率、工作表现、需求与疲劳休息逻辑。每份需要8工作量，不是固定8秒。

原回车及1–5即时手动制作保持不变。研究和装备仍需玩家自行制作；每设施只有一份委托，不能堆批量队列。同一时刻一名有效工人推进，不按人数重复发货。

原料**留在玩家背包，完工时按原配方原子扣料并发货**，不预扣或凭空产出。缺料、产物满格、暂停、非工作状态不推进；取消／拆设施不扣原料，取消会丢弃已投入工时。背包原料可能被手动制作或其他委托用走，剩余委托等待，不产生负库存。产物仍进入原背包，不含设施库存、搬料动画和加工运输链。

工作完成按原伙伴生产入口记录、加1经验，伙伴转为该设施旁普通休息，不自动开始下一份或意外继续采资源。原资源工作在设施没有委托时仍走原采集系统。F取消伙伴指派并改为跟随，不取消设施委托；需要留在设施旁暂停时，再T瞄准该设施休息，之后E续工。疲劳／进食复用原工作恢复管线，设施进度不会随临时活动切换清空。

## 存档与事务

设施记录独立修订`CraftRevision=1`，保存`CraftRecipe`与`CraftWork`；总格式保持38。旧记录修订0只接受空委托／0进度，不补发原料、产物或经验。未知修订、未知／非物品配方、非制作设施委托、非有限／负值／越界进度，以及基地专用配方的不合法设施位置，在恢复世界前拒绝。

实际委托只允许自建设施，因此仍由原设施稳定ID、支撑与伙伴工作关联恢复。运行时工人占用只是弱引用，不写入存档；新进程从真实有效指派重新认领，进度和库存保持。取消、倒地、休息或改派后不由无效工人继续工作。旧版程序不具备此委托能力，不建议用旧构建回写新委托存档。
