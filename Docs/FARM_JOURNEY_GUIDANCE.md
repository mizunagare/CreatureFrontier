# 农业旅程状态引导

## 问题与变化

第四项启程旅程要求伙伴收获两份食物，但旧提示只有建造农圃、按E派工，没有说明种子来源、入圃和粮仓已满等前置条件。空农圃即使派工也不会免费生产，玩家可能误以为伙伴失效。

本次仅将该阶段的提示改为只读状态查询，复用原农业、配方、仓储、需求和目标进度。优先说明已派伙伴正在使用的农圃，否则选择最近农圃，避免近处空圃盖掉原工作提示。

- 无农圃时说明建造及缺少材料；远离农圃时用已有世界方位和直线距离引导接近，明确不是路径。
- 空圃无种时，引导在基地C选择“准备种子”，需要原食物／纤维；缺食物可按原3制作。
- 背包有种时提示3米内瞄农圃F2存种，再E派伙伴。
- 已有种或作物但未派工时，提示E派工，并解释旅程只记录伙伴收获，不计手动收获。
- 粮仓满时优先提示6米内O取粮腾出空间；伙伴已派工时提示留出通道并查看饱食／体力。

没有改18材料农圃成本、种子配方、产出、奖励、任务或存档38。此项不是新农业系统，也不修复静止玩家挡住农圃时的自动绕行问题。
