# 建成家园的取粮、照料与归队

## 玩家操作

延续已有的原生伙伴结交、六处资源采集、原伙伴运料建房和农圃工作流程，不新建独立的生活菜单。

1. 为原农圃准备种子，按E派原伙伴工作；打开房门并保留庭院通道，等待实际完成一轮生产。
2. 玩家经庭院和已开启的门进入家园，瞄准农圃按O取出产粮。食物从设施库存进入背包，不会在生产时自动发给玩家。
3. 瞄准原伙伴，按F取消工作并归队；需要只指挥一位时先瞄准按L选择，K可恢复全队指挥。伙伴饱食不高于80、在6米内且视线无阻时，按J花1食物喂食。增加35饱食、15体力和3亲密度，均沿用原上限／3秒冷却。
4. 玩家走出原门和庭院，等待伙伴实际跟上；需要再次生产时重新存种并派工。离开前按F5保存，F9按提示确认读取；先备份重要存档。

这是一轮使用家园产粮的最小生活循环，不是完整的烹饪、睡眠、家具或长期生态模拟。农圃无种子时不会凭空开始下一轮，也没有自动转移背包或储物箱中的种子。
