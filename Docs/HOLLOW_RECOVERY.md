# 洞窟倒地与伙伴重聚（开发中）

## 缺口和本轮方案

已有隔离复活专项验证基地安全落点、保护时间与世界保留，尚未证明从洞窟自然战斗倒地后，伙伴能实际沿原洞道返程，再共同继续探索。本轮扩展既有连续冒险，不另造独立关卡或复活系统。

`CFHollowRecoveryTest` 当前出发夹具使用18生命的玩家、一级岩角兽，以及原冒险的背包/研究资格；这不是完整健康新角色的自然成长链。所有自然住民保留，不修改敌人生命/攻击/速度，不直接扣血。进入洞窟通过正常移动/一次左键近战挑衅，等待三级自然住民真实击倒，并要求此时敌人残血；再由唯一R绑定触发既有基地复活。只有这一次授权的复活位置跳转不计入步长，伙伴全程仍检查连续移动、碰撞、存活和启用状态。

R同一事务前后比较敌人/伙伴生命、伙伴身份、自然住民引用、完整背包及6份有限来源，不允许免费治疗或重置世界。在基地停留等伙伴真实返程至少2500厘米、进入300厘米范围后，重新按左Shift沿原路线二次进入，继续真实技能/承伤/击败、战利品守恒、采集、返家加工与存读。新流程180秒门槛仅用于新增多程恢复，原冒险75秒门槛不改。

使用独立测试槽HollowRecoveryCross，`CFHollowRecoveryRead` 在新进程读取最终快照。存档仍28。左键经引擎InputKey/Action链，R/Shift/Q/G/M走唯一注册按键委托，均不是操作系统键盘端到端。尚不覆盖倒地中途退出重进、伙伴同时倒下、全新角色成长链、任意堵路或大队伍恢复。
