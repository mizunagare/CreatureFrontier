# 主动休息与原任务续工

## 玩法改变

原T命令会清掉工作并转为无限期基地休息，自动耗尽体力的休息却会保留任务。现在有正在执行或自动休息中的有效任务时，T保留原设施、野外资源目标、施工工地及携带物，转入已有休息流程；达到原恢复条件后自动续工。F仍是明确取消工作并跟随。没有原任务时，T仍要求主人靠近8米内工作设施，回设施休息且不自动派工；暂停、主人倒下和非权威端不执行。

有任务的主动休息不再要求主人靠近另一座工作设施：野外任务沿用原地休息，设施任务沿用原设施，施工任务沿用原施工休息。没有新增床铺、休息计时器、恢复倍率、生产奖励或存档字段，格式仍38。原恢复门槛仍为体力80、饱食20、生命80%，原野外／施工休息不自动回血，原设施休息回血规则不变。主动休息仍按原SetActivity清理尚未结算的个人采集进度，不退还工作时间；已种作物生长和已付材料／携料保留。

现有T操作与F取消说明已同步在帮助、伙伴和农圃提示中更新，不新增快捷键；显示文字统一简体中文，不修改展示资产。

若需要放弃原野外／施工任务并回设施疗伤，可先F取消，再在设施8米内T普通休息；保留任务的原地休息不凭空获得设施回血。
