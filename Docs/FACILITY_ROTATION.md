# 工作设施手动旋转

## 功能与原规则

补齐自由建造中的设施旋转：原9键只在房屋类别生效，设施只能随视角自动吸附朝向。现在B进入设施模式后可按9每次转90度；手动旋转后，继续移动／瞄准只改变位置，不再把朝向转回视角。V切换设施类型保持当前手动朝向；8切到房屋仍使用原房屋旋转，切回设施保留设施朝向。取消／读档后再次进入恢复原随视角模式。

未按9时保留原视角90度吸附。手动状态只是运行时预览，不写入存档；实际建成设施继续由原Transform保存朝向。不增加按键、反射字段或存档版本，不改位置吸附、成本、支撑、碰撞、放置距离、门扇预留与导航规则。设施面板显示角度和“手动／随视角”，帮助改为通用9旋转。

本轮优先处理P1实际摆放缺口，不重跑加工配方或消耗上一轮加工药品。使用此前真实补采完毕的15材料检查点，不声称本轮重新执行了此前14材料采集。

## 验收方式

`Scripts/Test-StarterWorkshop.ps1 -Resume -VerifyRotation -Preview -ReadInputPath <实际建造前材料检查点>`：

- 通过原注册9键旋转90→180，改变视角跨过另一个吸附朝向，下一帧仍保持180。
- 验证四次旋转回原朝向，再转到270；切换全部设施类型、切到房屋旋转再切回，保留270。
- 视角此时对应90吸附方向，实际设施仍以270放置在原屋内`(100,-400,5)`；原15成本实际支付，尺度、支撑、两设施和七模块身份保持。
- 原烬尾兽仍能实际进入并在旋转后的设施休息，原农夫继续原农圃Work；源库存／经验／伤势、生态与位置存读保持。
- 读档后检查预览回到随视角，再手动旋转、取消和重开，确认旧手动状态不泄漏。

旋转专项需使用**建造前**检查点。读取本次已建成270方向的实际检查点时，使用`-Resume`而不加`-VerifyRotation`，验证真实变换和伙伴关联的新进程恢复。输入是引擎绑定验证，不是操作系统鼠标验收。
