# T瞄准休息设施与原任务保护

## 原问题与实现

原CommandRest总选玩家8米内最近设施，不读取视线；因而玩家看着较远农圃按T，空闲伙伴仍可能去更近的制作／采矿设施。现在：

- 视线看清且距离不超过原8米的工作设施优先，反馈标明类型和“瞄准”。
- 未看清设施时沿用原8米内就近选择，反馈明确“就近”。不扩大实际指派范围。
- 13米内看清但实际超过8米的设施，只用于反馈超距；空闲／普通休息伙伴保留原状态，不偷偷改派到其他附近设施。
- 原有任务中的伙伴T仍保留原工地／资源／设施和携物，休息后续工；瞄准别处或远处也不重定向它们。要改成别处普通休息，先L单选、F取消原任务，再瞄设施T。单只与全队范围沿用L／K。
- 暂停、倒地、权威门槛及原恢复速率不变；不新增床铺、付费项目或存档字段。

玩家操作：L单选要改派的伙伴；有工作则先F取消。看准8米内设施按T；看空处按T则就近安排。没有设施时保留原需要靠近基地设施的反馈，不把视线穿过遮挡物选择后面的设施。
