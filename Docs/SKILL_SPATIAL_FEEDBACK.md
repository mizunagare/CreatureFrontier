# 伙伴技能空间反馈（开发中）

## 本轮目标

第一人称下，伙伴站在视野外发动技能时，原实现只有脚下光圈和反馈文字，玩家难以辨认技能来源。为实际命中的技能增加从施法者到目标的短时三维轨迹，而非再加一个独立面板。

## 实现边界

`ACompanionSkillTrail` 是不进入存档的短命表现Actor，使用七个不碰撞、不影响导航、不投射阴影的网格标记，沿结算时的位置连接双方，0.5游戏秒后销毁。配色使用物种已有AccentColor和PaletteMaterial；叶、岩、烬使用不同基础形体。标记由普通深度渲染遮挡，不提供隔墙轮廓；不移动摄像机、角色或伙伴，不增加攻击和资源结算。

轨迹只在ResolveSpecial通过既有目标存活、归属、返巢、射程和视线判定后生成，与真实伤害使用同一结算分支。这是命中反馈，不是可拦截的飞行弹道，不延后或改动伤害/减速/护盾/溅射。现有蓄力光圈保留。瞬时命中后目标移动不追踪，读档不重建轨迹。

几何网格仍是灰盒表现，不等于正式模型、动画、音效或粒子特效。轨迹可能完全处于玩家背后，不据此宣称已解决全部画外技能辨识；普通窗口、实际冒险取景、遮挡和性能仍需验证。
