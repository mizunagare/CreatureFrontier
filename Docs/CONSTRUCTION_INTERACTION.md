# 施工料源提示与开箱补料

## 目标与实现

沿用原施工、运输、仓储及输入绑定，改善玩家发现料源选择、派工和缺料补料的方法，不增加菜单、任务或库存系统。V选箱仍能设置原资源运输目标；现在也明确其施工料源用途，左侧持续显示所选箱材料数，瞄准所选箱显示“当前料箱”。未选箱便对工地E会明确拒绝并提示先V选箱，避免将料源缺失和伙伴不适合派工混为一谈。

工地提示直接读取原伙伴任务、携物、料箱、已交材料和需求，不保存第二套状态。区分未派工、携料、缺料等待、材料已齐／正在施工、进食及休息；箱内为空但伙伴携料时不报缺料。缺料时提示E开原箱存材料，已有任务自动继续。存读仍清除玩家临时选箱，但工地既有料源与伙伴任务保留，因此已有任务补料不需要再V或E派一次。格式仍38，没有新资产展示字段。

## 验证流程

在原 `Scripts/Test-Construction.ps1` 等待专项加 `-InteractiveRefill`，使用已注册的E、V、回车委托：先验证未选料源拒绝，V选箱并核对3材料，E派原伙伴；伙伴携3材料后箱内显示0且工地显示携料，而非缺料。保留原取消取回／独立存读和坏档检查；首批交完后五秒缺料等待，E打开3米内可见原箱，回车三次存入3材料，再E关箱，原施工任务和料源不变。伙伴真实搬完补料、施工、进食休息及保存恢复，材料总账仍72，最终66材料＋6已建墙成本。

这是引擎绑定及真实仓储距离／视线检查，不是操作系统键鼠测试。场景仍为固定家园组合和玩家观察站位，补料来自明确背包夹具；实际采料楼梯整合由原楼梯补料专项关联，不把本单元称为自然采集开局或长期经营。
