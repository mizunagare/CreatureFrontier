# 按需取一份食物（限定交付）

## 用途与操作

为准备配方原料时保留基地口粮，瞄准6米内可见农圃／食槽，Shift＋O只取1份。原O仍取最多5份、U仍存最多5份，实际数量受库存／容量限制；满包、空库、遮挡或非食物设施不转移。反馈显示实际存入／取出数量，设施提示和F1帮助同步。

只增加原事务的单份取出上限与原生按键绑定，没有新增物品、优惠成本、存档字段或资产。普通O／U调用默认参数保持原行为，格式仍38；不支持自定义数量或单份存入。
