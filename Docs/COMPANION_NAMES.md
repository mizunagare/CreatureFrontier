# 伙伴个体昵称（格式 25）

## 玩法与边界

瞄准自己的存活伙伴按 F4，或在 Tab 队伍里高亮后按 F4；仍须 2.5 米、视线通畅、跟随/休息状态，附近 6 米没有存活野生生物。工作/战斗、其他主人、倒下、过远、遮挡或暂停不能开启。自动休息允许改名，不取消恢复意图。

原生 Slate 单行文本框暂停 Windows 单机世界并切换 UI-only 输入；Enter/确认提交，Esc/取消不改名，关闭恢复游戏输入和鼠标。非法文本保留窗口供修正。成功读档和主人倒下关闭窗口；目标外部销毁时提交拒绝，可取消，不将旧昵称转给新 Actor。离开关卡移除窗口。开启时其他面板关闭/拒绝，队伍高亮不替代距离权限。

昵称只是个体身份的显示名，不修改物种 Data Asset、Actor 对象名、GUID、亲密度/经验或战斗数值。允许同名，绝不按名字合并角色；原队伍/编队排序仍按 Actor 名，不因改昵称重排。队伍和瞄准显示保留物种信息，原照料/战斗/食槽提示共用 GetCreatureName。真实变化触发短暂原有 Affection 占位动作，不刷新抚摸冷却或赠送关系数值。

前后空白在提交时裁掉；空白昵称恢复物种默认名。上限 24 个 UTF-16 单元（普通汉字通常 1、补充平面字符通常 2），不是 24 个任意视觉字素。允许中文和一般可打印字符，拒绝换行、制表、C0/C1、若干零宽/方向控制和孤立代理项；纯文本显示，不是富文本标签。并非全 Unicode 字素/混淆字符过滤器或反作弊系统。

## 持久化

格式 25 显式写盘，读取默认仍固定 21。生物记录追加 Nickname，非规范长度/空白/控制数据或非玩家拥有、非驯服生物携带昵称时拒绝，旧世界不替换。已驯服倒下伙伴可保留昵称；改名入口本身要求存活。1–24 忽略未来昵称字段、保持原 ID/属性和物种名，不自动命名。读取旧快照是时间线恢复，不保证旧文件本来存在个体 ID；无版本历史档推断边界仍保留。
