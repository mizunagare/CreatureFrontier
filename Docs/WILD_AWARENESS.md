# 洞窟遮挡与野生警戒（首版验收）

## 现有缺口与方案

余烬洞窟的岩壁有真实碰撞和伤害视线检查，但旧野生警戒按最近距离直接选择目标，会隔墙进入战斗/追击。伙伴未收到显式集火命令时也会自动选择墙后目标。这削弱弯道、掩体和进入区域的探索节奏；先修正规则，再补综合战斗往返，不增加另一套敌人系统。

首次警戒在现有AggroRange内选择最近的可见玩家或存活伙伴，被遮挡的近目标不能屏蔽可见的较远目标。没有新增视野角或听觉系统。失去视线后保留3游戏秒，只导航到最后看见的位置，不持续读取隐藏目标的新位置；超时恢复原巡游。记忆只在运行时存在，读档不保存锁定，不升级格式28。

受到实际伤害后的12秒、20米范围反击沿用旧规则，是明确保留的例外，并不是完备隐身/听觉系统。首领已开始的蓄力继续结算，但仍逐受害者验视线。回巢、倒地、驯服等清理战斗状态时也清理短时视觉记忆。伙伴自动发现需要视线，玩家显式集火/技能命令仍沿用可绕行追击，不要求目标始终可见。

## 后续综合场景

自然栖息地保持人口/AI运行，从基地连续进入洞窟，观察实际发现、绕障追击、伙伴普通攻击/技能与伤害，然后采集返回。不得用直接扣血、冻结敌人、瞬移或关闭碰撞替代实战；需要同时结算击败掉落与有限来源，防止测试因多出真实战利品而误判或直接抹掉差额。倒地分支需验证战斗订单终止、存档和资源不重复。

现有伙伴自动选敌仍沿用“可见且主人附近的未驯服生物”，没有新增防御/被动战术；因此可能主动攻击温顺野生生物，影响带伙伴和平结交。这不是本次视线过滤已解决的问题，下一步需结合关系/指挥规则优先评估，而非将自动攻击所有野生当作最终设计。
