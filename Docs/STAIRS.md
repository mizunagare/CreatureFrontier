# 木楼梯与二层连接（两层灰盒首版）

## 本轮目标与结构规则

在原模块化建筑上实现可实际上下通行的两层组合，而不是新增孤立楼梯装饰。原地面木地板中心仍为-40厘米、表面-30厘米；二层木地板中心280厘米、表面290厘米，层高320厘米。二层复用原木地板定义与8材料成本，需要正下方原地板及其两面相对的墙支撑。上层墙、门窗、栅栏、灯、箱子和屋顶均以所在楼板为基准定位；工作设施也可在二层合法平面上放置。

新增“木楼梯”成本12材料，4米长、2米宽，底端留50厘米平坦入口，其后16级实体踏步、级高20厘米，连接下层地板与上升方向相邻的二层地板。复用B／8／V选择和9旋转，楼梯有四个朝向，原墙类仍保持两种轴向。楼梯必须有现成的上层平台，不能直接建到空气里；上下两端及踏步上方保留两米通行净空，不使用隐形斜坡、不关闭实体碰撞。

拆除与读档共同检查支撑关系；上层楼板依赖下层墙体，楼梯依赖上下两个平台。新增结构与设施不能侵占楼梯实体／净空，拆楼板或承重墙不能留下悬空的上层模块。首版仅两层，不包括任意高楼、曲线楼梯、坡地基或正式美术。

## 玩家操作

1. 在相邻两格放木地板；为上层平台所在的下层格放两面相对的墙。
2. 选木地板，瞄准承重墙上半部，预览会向上吸附一层；已有平屋顶需先按正常拆除流程移除，不能与二层地板叠在同一安装位。
3. 选木楼梯，瞄准邻格的下层地板，按9使上升端朝向已建二层平台，确认绿色预览后放置。保留楼梯格上方开口，不能给它加会挡头的低屋顶。
4. 在二层地板上放墙、屋顶和储物箱，实际走上楼存取物资，再带伙伴走下楼。不要在楼梯口放置会阻挡通行的设施。
